# UI Touch Hub ↔ 音频引擎 UART MIDI 通信协议规范

> **基准文件**：参考 `synth1_9_18/docs/midi_control_protocol.md`  
> **电气标准**：标准 3.3V CMOS 异步串行通信 (UART)  
> **数据位格式**：8N1 (1 起始位，8 数据位，无校验，1 停止位)  
> **标准波特率**：默认 `31250 bit/s` (兼容标准 MIDI 规范)，顶层参数支持一键配置为 `115200 bit/s` 高速模式。

---

## 一、 通道分工与消息结构

UART 链路传输标准 3 字节 MIDI 消息包：
```
+---------------+----------------+----------------+
|  状态字节     |   数据字节 1   |   数据字节 2   |
| (Status Byte) |  (Data Byte 1) |  (Data Byte 2) |
+---------------+----------------+----------------+
```

### 1. 通道分工
| MIDI 通道 | 状态码前缀 | 用途 | 接收端处理规则 (队友 3 音频核) |
| :--- | :--- | :--- | :--- |
| **Channel 1** | `0x90` / `0x80` | **演奏音符事件** (虚拟琴键触发/释放) | 路由至声部任务调度器 (`oscillator_task_scheduler`) |
| **Channel 16**| `0xBF`          | **合成参数控制** (CC 控制旋钮) | 路由至全局参数寄存器堆 (`global_param_regs`) |
| 其他通道 | `0x81~0x8E` 等 | 保留 | 接收端静默忽略 |

## 二、 演奏音符控制 (Channel 1)

### 1. Note On (按下琴键)
- 格式：`0x90, Note_Number, Velocity`
- `Note_Number`：音符编号 (十进制 48 ~ 71，对应中央 C3 到 B4 两个完整八度)；
- `Velocity`：按键力度 (0 ~ 127，触控屏默认 `100`，支持根据触控面积/滑动速度动态映射)。

### 2. Note Off (松开琴键)
- 格式：`0x80, Note_Number, 0x00`
- 触发声部释放阶段 (进入 ADSR Release)。

## 三、 合成参数控制 (Channel 16, Control Change)

所有合成参数通过 `0xBF` 状态码发送：
`0xBF, CC_Number, CC_Value`

| 功能分类 | 控制参数 | CC 编号 (Hex/Dec) | 数值范围 | 复位默认值 | 作用说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **声像定位** | Pan | `0x0A` (CC10) | 0 ~ 127 | 64 | 0=全左，64=居中，127=全右 |
| **波表位置** | WT Position | `0x14` (CC20) | 0 ~ 127 | 0 | 16 帧多帧波表连续扫描与帧间插值 |
| **基础波形** | Waveform | `0x15` (CC21) | 0 ~ 127 | 64 | 0~31 正弦, 32~63 三角, 64~95 方波, 96~126 锯齿, 127 多帧 Acid |
| **失谐深度** | Detune | `0x16` (CC22) | 0 ~ 127 | 64 | Unison 各声部微调失谐量，64 为标准音差 |
| **同音复音** | Unison Count| `0x17` (CC23) | 1 ~ 8 | 1 | 振荡器叠加同音发音数 (限制在 1..8) |
| **滤波器** | Cutoff | `0x4A` (CC74) | 0 ~ 127 | 80 | 截止频率对数扫描 (20Hz ~ 20kHz) |
| **滤波器** | Resonance | `0x47` (CC71) | 0 ~ 127 | 32 | 共振峰 Q 值倍数 |
| **包络起音** | Attack | `0x49` (CC73) | 0 ~ 127 | 10 | 起音爬升时间 (0.5ms ~ 5s) |
| **包络释音** | Release | `0x48` (CC72) | 0 ~ 127 | 35 | 释音衰减时间 (1ms ~ 10s) |
| **包络衰减** | Decay | `0x4B` (CC75) | 0 ~ 127 | 40 | 衰减到 Sustain 时间 |
| **包络延音** | Sustain | `0x4C` (CC76) | 0 ~ 127 | 90 | 延音保持电平 (0~100%) |

## 四、 硬件发送节流机制 (Traffic Throttling)

在 31250 bit/s 标准波特率下，传输一个 3 字节消息约需 `0.96 ms`。若用户手指或物理旋钮连续快速旋转，可能瞬时产生数百次参数变化。
本模块设计了**硬件智能变动检测与节流器 (Rate Limiter)**：
1. **变化触发 (Change Driven)**：仅当参数值发生真实改变且满足死区 (Hysteresis) 时，才排队发送；
2. **状态更新合并 (Late-binding)**：每个参数在发送等待队列中只保留最新值，若前一个值未发完且新值到达，直接以后写覆盖更新目标寄存器，绝不阻塞总线；
3. **琴键事件最高优先级**：Note-On / Note-Off 享有最高抢占权，零延迟插入参数流，确保演奏响应绝对灵敏。
