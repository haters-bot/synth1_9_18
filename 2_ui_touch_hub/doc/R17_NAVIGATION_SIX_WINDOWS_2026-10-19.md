# R17：六窗口可视化、导航菜单与系统页

## 本轮确认的范围

用户选择 **一屏同时显示六个小窗口**，允许先预留位置，以后再增加实际内容。采用3列×2行，不做六个独占全屏页面。保留原合成器布局和已验收触控，顶部低利用率区域按真实功能精简，左上横杠用作菜单。

已核对 `VISUALIZATION_PHASE2_PLAN.md`：当前 UI 尚无音频PCM或键盘Note事件输入。六窗口均显示等待数据，不画伪实时波形或演奏数据；本轮没有FFT、I2S/高速遥测物理接入或音高检测实现。

## 画面与操作

- 顶部：左上四横线+MENU，SYNTHESIZER、VISUALIZATION、SYSTEM、USB状态；合成器页保留原Master，其他页面右侧显示UI TOUCH HUB。
- 左上菜单展开为三张导航卡片；再次点MENU返回进入菜单前的页面，也可直接点顶部页签。
- 合成器页仅精简顶部，OSC/FILTER/ENV/FX/LFO位置和功能不变。顶部±和通用选中参数滑条由导航层遮盖且触控拦截；旧RTL仍保留，便于审计回退，不删除原始文件。
- Macro1..4原有参数、SPI通道12..15、MIDI CC1..4保留；从主界面移到系统页的扩展控制。±每次接触改变1，继续经param_merger处理仲裁/饱和和原MIDI路径。本轮未新增宏多目标分配或音频宏映射。
- Master仍在合成器顶栏原位置，保留旧触控/MIDI编号，不把它当作冗余HUD删除。
- 系统页显示真实USB状态、1280×720、像素50MHz、约40.4Hz、本轮R17版本及SRAM部署方式。音频可视化/Note输入明确未连接。
- 系统页可切换触摸底栏与紫色诊断十字显示，默认隐藏；开关仅影响显示，不关闭触摸采样或串口诊断逻辑。
- 没有亮度、分辨率、Flash保存、音频设备选择等无后端功能的假设置。

## 六窗口布局

外框左上角依次 `(24,96)`、`(442,96)`、`(860,96)`、`(24,392)`、`(442,392)`、`(860,392)`；每框397×279像素（含边界）。未来绘图区限制在内框，顶部标题和底部数据状态保持。

| 位置 | 标题 | 等待的真实数据 |
|---|---|---|
| 左上 | NOTES | Note On/Off、音高、力度、时间戳 |
| 中上 | SCOPE | 同步左右PCM、采样率、触发/帧序号 |
| 右上 | LISSAJOUS | 同采样时刻L/R PCM |
| 左下 | SPECTRUM | PCM分析结果或频段能量 |
| 中下 | WATERFALL | FFT帧与历史索引 |
| 右下 | METERS | 真实音频电平/声部/调制统计 |

本轮不是六个分析引擎；后续独立数据链路、双缓冲、失联判断、FFT资源与协议仍按前期规划逐项实现。未改变队友工程或擅自制定物理引脚。

## 控制与视频隔离

- 新 `ui_navigation_state`：view=0合成器、1六窗口、2系统、3菜单。请求在VSYNC上升沿提交，沿用唯一视频时序发生器；切页不复位USB、参数库、FX或LFO。
- 导航触控捕获同时接至旧路由器和曲线编辑器；FX/LFO编辑器接收被屏蔽的down作为release。导航页及待切页时输入不穿透修改背景参数。
- `lfo_binding_state`新增可选cancel，默认关闭以兼容旧独立测试；实际顶层开启，在导航触摸时清除armed/dragging/临时捕获，保留sources/depths/选中目标，不将离开页面当成有效drop提交。
- 导航渲染器单独寄存局部光栅输入，5拍图层流水接到最终合成器，与现有总7拍像素/HSYNC/VSYNC/DEN延迟对齐。
- 宏±输出 `navigation_delta_valid/id/value`，顶层合并到参数库相对事件入口；后台SPI继续工作，不随页面切换关闭。
- `navigation_labels.vh`由 `tools/generate_navigation_labels.py`生成，复用现有7×10覆盖字体；大标题2倍显示。界面英文受当前字体字符集限制，未添加假中文乱码。
