## 实现

- I2S 接收器保留原左声道 sample_valid 的输出时刻，新增完整右声道及配对有效脉冲。两个不同左右字和生产单声道复制均经仿真验证；不把单声道伪造成立体声。
- 第三窗：真实左右 PCM 的 128×64 双缓冲散点图，横轴 L、纵轴 R，每 8 对取一点，每 2048 对提交一帧；非显示缓冲区逐项清空。单声道复制应为对角线，静音为中心点。
- 第四窗：连续 1024 个原始 96 kHz 左声道样本，周期 Hann 窗，定点 radix-2 FFT，每级右移一位。处理期间样本不进入该帧，处理时间 <1 ms；每帧内部采样连续。频率间距 93.75 Hz，32 个逐渐变宽的频带覆盖 bin 1..511；不显示 DC bin。柱高为近似绝对实部加虚部后的相对对数幅度，不是校准的 dBFS、RMS 或音符识别。
- 第五窗：同一 FFT 频带结果，每 8 帧向 64 列环形历史写一列，低频在下，高频在上，时间由左到右。未填充区域及静音无伪造色块。
- 断线立即撤销有效标志；重连须等新帧，旧 RAM 不会冒充当前数据。
- 三个新图的地址、同步 RAM 读取、覆盖率和混色使用既有流水级，保持五拍导航、七拍整体视频延迟。
- 字体未变；新标签只有第一窗保留 EXAMPLE / NOT LIVE。频谱与历史使用真实 PCM 数据；部署后的用户现场验收已通过。
