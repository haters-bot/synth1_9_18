# 六项 UI 修复与验收

本轮目标：源码修复、仿真、一次统一 Gowin 候选、完整审计，再仅写 UI SRAM operation 2。Flash 和音频工程不改。最新状态以 CODEX_HANDOFF.md 顶部为准。

## 最终行为与接线

1. 音域统一为 MIDI 29～60，共32键。UI顶层、手机状态上报、输入范围、屏幕和灯带按相同编号。
2. 录音始终来自音频板 I²S→UI DDR。手机收到完整 PCM 后才允许导出 WAV；每个 AUDIO 包推进下载百分比。新版安卓 0.2.0 / versionCode 2 必须安装，旧 APK 不会因 FPGA 更新自动改变。
3. AUDITION 试听发送标准 Note On/Off；FOLLOW 等正确实体按键才推进；PERFORM 按曲谱时间提供灯屏指引。切换模式停止当前播放，Stop/Pause/重启会清理试听已发音符。模式、播放、暂停、停止、录音可点击；缺失显式触摸 UP 时50ms静默释放，滑键先 Off 后 On。
4. 24颗灯按 MIDI29起的19个白键从左到右映射；最后5灯熄灭，13个黑键只在屏幕显示。
5. LFO 保留53目标号与 MIDI-safe 14bit 编码。真实 FSM→renderer 快照→q/sh→UART 已覆盖6/13、释放、解绑、重绑、LFO2/3、无UP超时及 Note/CC/Commit 仲裁。
6. ENV1 ADSR→CC24～27；ENV2 ADSR→CC32～35；ENV3、所有 Hold 本地。ENV2内部ID58/59/5A/5B/5C（16进制，其中59=Hold）。入口捕获bank，pending按bank固定ID发送；触摸、SPI绝对/增量及曲线在双向忙切页下覆盖。

实体键盘的转换模块 TX 保持接音频 E19，并联到 **UI F15 / J13第34脚**；共地、3.3V UART、31250 baud/8N1、空闲高/起始低。UI只监听，不重复转发物理音符。不要将两个发送端相连。改线先断电。官方 Dock31005 Rev1.3 原理图第7页 F15=Bank2 IOR1A/SDRAM0_BA0，第19页 BA0=J13 pin34；与当前DDR3/旋钮/蓝牙约束无冲突。蓝牙仍F14 TX/F16 RX，灯带仍F13。

**音频依赖已获用户明确分工确认**：2026-10-31 fetch的 origin/main=5224279 中 C19 的 `u_control_cc_parser.note_event_*` 未连接，因此当前音频固件会忽略试听 Note。用户选择由队友补齐 C19 Note接收，本轮继续完成UI。UI可发声控制链验收不等于音频板已能试听，具体交接见 AUDIO_C19_NOTE_HANDOFF_2026-10-31.md。

## 根因与修复边界

- WAV实证：用户文件实际44字节，头部data却声明274720字节（137360个8k单声道帧，17.17秒）。这不是“录了空白声音”，而是根本没有PCM文件内容。旧版先在Documents创建最终文件、写头，再等串口数据，超时/退出会留下该残片；进度只在大块完成后变化。现在先用唯一应用缓存，严格检查PCM字节数、帧对齐及缓存长度，完整后才弹保存位置并复制；失败不导出残片，缓存保留。究竟为什么那一次实物传输没有首块PCM，没有日志不能认定；板端I²S/DDR/FIR、手机协议和原生缓存均有独立回归，实板回传仍须复测。
- LFO可重复竞态：S_LATCH锁存最新q数据，却采用落后一拍drt_vec作为dirty。绑定恰在批次锁存时到达，可能q/sh已变1但dirty=0，从而永久漏发。旧源码HOLD56失败：cycle414 qsrc=1 dvec=0；修复后同边界通过。现在dirty直接比较同拍锁入的q与旧shadow，nodes/mode/phase/route保持一致。**该复现是路由漏发，尚未逐字节复现用户历史0000帧；不能说已唯一解释历史抓包。** 真实绑定6/13的完整renderer串行测试通过，音频板/实物绑定仍须上板复验。
- ENV2：旧发送门限和增量分支仅允许ENV1，且增量基值可能受切页影响。现在入口保存bank、独立参数ID和待发位图，不在UART出队时读取当前页。
- 按钮：模式曾只有命中区没有文字；补三个可见选中按钮。演奏控件和手动键的接触锁存曾仅靠UP释放，新增静默释放并验证缺UP后连续操作。

```text
LFO1 target6 : F0 7D 4F 02 7F F7
LFO1 target13: F0 7D 56 02 7F F7
Commit       : F0 7D 7E 00 00 F7
解绑target13 : F0 7D 56 00 7F F7  （source=0，保留深度127）
LFO2 target6 : F0 7D 4F 04 7F F7
LFO3 target13: F0 7D 56 06 7F F7
ENV1         : BF 18 1F / BF 19 20 / BF 1A 21 / BF 1B 22
ENV2         : BF 20 29 / BF 21 2A / BF 22 2B / BF 23 2C
试听第一音   : 90 1D 64，停止释放 80 1D 00
```

绑定后source[6]/source[13]=1，depth=7F，对应source快照[13:12]/[27:26]、depth[55:48]/[111:104]，q/sh逐级断言一致。解绑才变source0；普通抬起不清空。
