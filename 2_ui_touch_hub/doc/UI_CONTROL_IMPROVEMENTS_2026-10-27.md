# 调节界面与可视化改进

## 已确认的需求

- UI LFO 预览独立于基础值：满深度显示曲线原值，0..127、10..20均原样跟随。AMOUNT保留，默认+127；正深度按abs(depth)/127缩放，负深度先取127-wave再缩放。无绑定时显示基础值。基础参数CC与曲线/速率/绑定/深度SysEx分别发送，不把预览逐拍写回或发送为CC。音频侧需按本语义实现计算，线上封包不改。
- 实体旋钮顺时针增加、逆时针减少，动作后高亮最后操作目标；触摸改变焦点后切换高亮，不能把实体焦点写进触摸编辑选择寄存器。
- SYSTEM → CONTROLS：32个实体旋钮分别设置每格1/2/4/8，提供全部应用；初始4。触摸拖动灵敏度不变。
- 显示缩放同时提供SYSTEM → DISPLAY与图内快捷入口，同步唯一配置。只改显示，真实RMS/dBFS/Hz等不改。
- 第二窗可调幅度/时间跨度，第三窗真实L/R缩放与立体声验证，第四窗可调幅度/频率显示范围，第五窗可调颜色强度/历史时间跨度；总览能量图可调显示增益。
- 第六窗：左右独立RMS填充、电平绿黄红区、左右峰值保持；保留dBFS、crest和CLIP。
- 李萨如图不保证任何输入都有椭圆：同相/单声道应为对角线，反相为反向线，同频相差90度应为椭圆。需验证独立左右通道及正交输入，不伪造相位。
