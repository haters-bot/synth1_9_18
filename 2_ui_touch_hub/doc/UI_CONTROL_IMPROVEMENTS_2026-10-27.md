# 调节界面与可视化改进

## 已确认的需求

- UI LFO 预览独立于基础值：满深度显示曲线原值，0..127、10..20均原样跟随。AMOUNT保留，默认+127；正深度按abs(depth)/127缩放，负深度先取127-wave再缩放。无绑定时显示基础值。基础参数CC与曲线/速率/绑定/深度SysEx分别发送，不把预览逐拍写回或发送为CC。音频侧需按本语义实现计算，线上封包不改。
- 实体旋钮顺时针增加、逆时针减少，动作后高亮最后操作目标；触摸改变焦点后切换高亮，不能把实体焦点写进触摸编辑选择寄存器。
- SYSTEM → CONTROLS：32个实体旋钮分别设置每格1/2/4/8，提供全部应用；初始4。触摸拖动灵敏度不变。
- 显示缩放同时提供SYSTEM → DISPLAY与图内快捷入口，同步唯一配置。只改显示，真实RMS/dBFS/Hz等不改。
- 第二窗可调幅度/时间跨度，第三窗真实L/R缩放与立体声验证，第四窗可调幅度/频率显示范围，第五窗可调颜色强度/历史时间跨度；总览能量图可调显示增益。
- 第六窗：左右独立RMS填充、电平绿黄红区、左右峰值保持；保留dBFS、crest和CLIP。
- 李萨如图不保证任何输入都有椭圆：同相/单声道应为对角线，反相为反向线，同频相差90度应为椭圆。需验证独立左右通道及正交输入，不伪造相位。

## 实现细节

- LFO 的乘法流水只计算曲线与深度，不再叠加静态基础值。精确除以 127 使用有界加法/移位，独立整数参考覆盖全部合法输入。指针、旋钮数字、白点、OSC/FILTER/ENV 曲线和顶部所选参数读数均接有效预览；基础值保持独立。
- 四相解码方向按用户报告反转。`knob_param_map.vh` 集中保存 PCB 编号，`knob_ui_control.v` 计算各旋钮步长，并单独保存显示焦点。触摸编辑选择寄存器不接收实体焦点，按下选中、松开不清除选中。
- CONTROLS 每页 8 个，共 4 页；32 项各自选择 1/2/4/8，默认 4，全部应用使用最后选择。配置是会话状态，复位恢复默认值，未增加 Flash 写入。
- K31/K32 的 UART 原始 ID 仍为 0x50/0x51；显示与数值分别适配至当前 FX 面板 Reverb Size 0x66 / Delay Feedback 0x60。增减以 FX 当前基础值为起点，触摸拖动仍有目标所有权，FX 选中外圈变白。
- DISPLAY 与每窗底部快捷入口共享 24 位配置。幅度统一为 1/2/4/8；波形时间跨度 10.67/5.33/2.67/1.33 ms（96 kHz）。相位 X/Y 独立且饱和，配置变化会重新清空采样银行，避免混合旧尺度。
- 频谱横向是现有对数频带的低频放大，不增加 FFT 分辨率。四档上界约 48000/2906/844/469 Hz，屏上显示上界，真实峰值和重心读数不随显示缩放改变。历史图每 8/16/32/64 个 FFT 帧写一列，切换会清空历史有效计数，避免混合时间尺度；完整窗口秒数还包含 FFT 处理间隙，不标成固定秒数。
- 第六窗为左右各一条 RMS 条和独立峰值保持。显示增益不进入 dBFS 读数或削波判断；快速上升、逐统计窗口衰减，峰值约 1 秒保持后衰减。绿/黄/红阈值按显示电平 -24/-6 dB 分区，CLIP 继续来自原始 PCM。
