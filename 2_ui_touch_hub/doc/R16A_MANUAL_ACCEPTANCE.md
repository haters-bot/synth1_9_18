本表是待执行的人工验收，不能据此声明已经烧录或用户已经通过。当前部署状态见 CODEX_HANDOFF.md 和当日工作记录。进入实屏验证前须核对本地提交、构建输入SHA256、最终P&R、双机位流SHA256与SRAM Programmer返回码；用户已暂停Flash。

## 触控与布局

| 操作 | 预期 |
|---|---|
| 依次点ENV1/2/3，并修改A/H/D/S/R | 页签独立保存；小面板内曲线与旋钮同步；FILTER和OSC位置未变 |
| 拖中央DELAY任一数值旋钮 | 初次按下不跳值；向上/右增、下/左减；0..127饱和 |
| 打开LINK，分别拖LEFT/RIGHT | 两者立即相等，拖任何一侧时一起变化 |
| 点REVERB开关和HALL/PLATE | 每次接触仅切一次，按住不重复切换 |
| 点EQ低/高类型 | BELL→SHELF→CUT→BELL，两个频段独立 |

FX值暂为归一化整数。BPM和滤波器类型保存配置；真实时间/频率/增益映射须与音频队友统一，不能仅凭UI动作认为声音已改变。

## LFO平滑、分配与标记

1. 选LFO1，拖不同白点：曲线穿过节点、平滑连接、不超过相邻节点电平范围；Square预设保持阶梯，编辑节点后转平滑自定义。
2. 点BIND LFO，再按住曲线图拖到FILTER CUTOFF，松手：自动退出分配；曲线节点不变；CUTOFF持续显示青色轮廓及L1。
3. 选LFO2，按同样步骤绑定DELAY MIX：MIX持续显示金色轮廓及L2；L1标记仍保留。
4. 选LFO3并绑定任意ENV旋钮：出现紫色轮廓及L3。绑定同一个目标会替换来源，其他目标不变。
5. 绑定模式拖到空白处松手：取消，不改参数或已有绑定。拖动途中有效目标显示白色候选，松手后保留来源颜色。
6. 点已绑定目标，再点AMOUNT −/＋：显示带符号深度；反复点击可到−127/+127；动态小白标改变方向/范围，基础值保持独立。
7. 点CLEAR：该目标持续轮廓与L编号消失，恢复基础值；其他目标绑定保持。
8. 返回直接编辑LFO节点、FILTER和ENV曲线：仍能跟手，无分配模式残留。

当前预览按本地时间运行，未连接Note On触发；不能把持续运动的旋钮视为音频调制已经联调成功。每目标一个LFO；多源叠加、双极性、独立ENV页目标与循环首尾连续性尚未扩展。

## 实体旋钮逻辑接口

- 按FX_LFO_INTERFACE_R16.md注入external_param ID/value，确认触屏显示更新。
- 触屏按住同一参数时注入外部值：触屏保持所有权；其他参数应继续接收；LINK配对参数也受保护。
- 确认FX事件/快照的EQ CUT为2，Enable为0/1，绑定source为0/1/2/3且depth按有符号解释。
- 慢速串口适配需另加dirty队列/提交与跨域处理；现有事件valid没有ready/ack。现有4位SPI channel草案无法直接表达所有19个FX参数，须先完成协同协议。
