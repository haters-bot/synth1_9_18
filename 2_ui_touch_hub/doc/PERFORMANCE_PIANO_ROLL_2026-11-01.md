# PERFORM 下落音符与时值指引

本次仅改 UI FPGA 的曲谱显示。实体灯带的 DIN 引脚、WS2812 时序和颜色逻辑不变；输入焊盘与中间连接处的机械接触故障由用户另行检查。显示功能烧录成功不能证明灯带电气连接正常。

## 行为

- 保留现有页面、按钮和 32 键虚拟键盘。轨道仍位于 y=192..399，琴键触摸区域仍从 y=420 开始。
- 每条彩色长条对应一个待弹奏音符；下端白色横边是起音，条长由 MIDI Note On/Off 决定。白边到达下方判定线时按键，长条尾端到达判定线时松键。
- 8 曲谱毫秒/像素，提前显示约 1.65 秒；很短的音符至少两像素高。超长音符裁切到窗口顶部，已经按住的音符下端停留在判定线。
- 同时显示和弦及多个后续音符。不会因调度器当前队列头是 Note Off 而隐藏后面的 Note On。
- 颜色由低键的橙色逐渐过渡到高键的紫/粉色；实际按键黄色反馈和原有曲谱引导保留。
- 使用与调度器相同的曲谱时钟。Pause 与跟弹等待不会让音符按墙钟继续下落；画面仅在垂直消隐交换缓冲，正常显示最多滞后一个显示帧和本次扫描用时。
- Stop、重新开始、清空或重新校准时废弃旧图，下一张完整图生成前不显示旧曲谱。

## 实现边界

`performance_event_scheduler` 在播放时复用空闲上传端口作同步预览读取，保持原播放读指针、事件次序、容量和 UART 行为。没有复制完整曲谱，也没有在逐像素路径中遍历事件。

新增 `performance_piano_roll.v` 从已加载的事件中配对起止，每个可见键记录开始时间及同键重叠计数。两个 208 行 × 64 bit 小图分别存放音符主体和起音边，端口 A 扫描/读改写，端口 B 连续显示；完整图在 VSYNC 交换。图行 RAM 的读地址来自原始 raster Y，结果与现有 raster entry 寄存器对齐，页面和合成器的总七拍延迟保持不变。

同键同时叠加的多个声部显示为它们的并集，最后一个匹配的 Note Off 才结束。该图是演奏提示，不对正确按键或节奏给出评分，也不改变现有实体键跟弹判定规则。

## 验证与构建

新增 `sim/tb_performance_piano_roll.v`：独立按时间格计算 4,140 行音符/起音掩码，覆盖 0x29/0x35/0x41/0x4D 四档、和弦、同键重复、长音、暂停、跟弹等待、重启/清空以及 16,384 事件容量。

新增 `tools/test_performance_piano_roll.py`：通过真实触摸进入 PERFORM、上传事件到完整 renderer，在原始坐标逐拍变化时检查最终像素和 HS/VS/DEN 七拍对齐；另生成整页合成结果的 8 像素间距采样预览。该预览不是原生逐像素截图。首次全分辨率截图因仿真开销中止，部分证据保留。

首轮 `R16A_build_20261101_210743` 在器件打包阶段失败：GW5A 不支持推断出的 DPB `WRITE_MODE0=2'b10`（read-before-write）。保留完整失败目录；未进入有效 UI 部署。曲谱预览端口和图形构建端口改成显式 write-through，写入时输出新数据，播放/图形读取语义保持不变。补丁后的独立 RAM 小工程完成综合、布局布线和位流生成；这只证明器件兼容性，不能代替完整 UI 时序审计。补丁前后的整页采样画面逐字节相同，4,993 移动像素检查及 normal/debug 展开再次通过。

完整 UI 构建、五类时序审计及 SRAM2 部署结果完成后补记。此段不能作为已烧录证明。

### 完整构建暴露的两处时序路径

第二轮 `R16A_build_20261101_211848` 完成位流生成，但审计有 55 个 setup 违例：像素时钟估算 46.946/50 MHz，DDR 用户时钟 89.196/100 MHz。最差路径为 LFO `scan` 到帧数据（-1.301 ns），其次为 DDR 初始化/复位状态经错误选择逻辑到录音返回数据（-1.211 ns）。其余四类时序没有违例；不能烧录该候选。

局部修补将 LFO 的 80 个条目选择先寄存为 one-hot，再以常量切片编码。选择标签必须与当前 scan 相等才允许发送，额外准备拍不会发送上一个条目，也不改变七节点、速率模式、53 目标、Restart 或 Commit。原绑定测试的固定 100 拍等待改为等待真实 Commit，并增加 source/depth 断言。

录音返回的 64 位载荷提前准备，错误位和有效信号仍实时检查校准、超时及会话状态。返回 FIFO 只在完整数据就绪后接收，没有放宽错误检查或时序约束。独立 DDR 两时钟比与实际 I²S→录音→导出链路回归通过。正式重建前还要完成 LFO RTL/官方网表字节对照及完整功能回归；仿真探针不得部署。

官方网表对照脚本补齐 `audio_capabilities.vh`、`audio_extra_controls.vh` 及其 `wavetable_catalog.vh` 依赖。此前缺失头文件的失败目录均保留，不能计为功能测试通过。
