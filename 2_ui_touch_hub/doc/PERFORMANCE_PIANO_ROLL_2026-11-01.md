## 行为

- 保留现有页面、按钮和 32 键虚拟键盘。轨道仍位于 y=192..399，琴键触摸区域仍从 y=420 开始。
- 每条彩色长条对应一个待弹奏音符；下端白色横边是起音，条长由 MIDI Note On/Off 决定。白边到达下方判定线时按键，长条尾端到达判定线时松键。
- 8 曲谱毫秒/像素，提前显示约 1.65 秒；很短的音符至少两像素高。超长音符裁切到窗口顶部，已经按住的音符下端停留在判定线。
- 同时显示和弦及多个后续音符。不会因调度器当前队列头是 Note Off 而隐藏后面的 Note On。
- 颜色由低键的橙色逐渐过渡到高键的紫/粉色；实际按键黄色反馈和原有曲谱引导保留。
- 使用与调度器相同的曲谱时钟。Pause 与跟弹等待不会让音符按墙钟继续下落；画面仅在垂直消隐交换缓冲，正常显示最多滞后一个显示帧和本次扫描用时。
- Stop、重新开始、清空或重新校准时废弃旧图，下一张完整图生成前不显示旧曲谱。

## 实现边界

`performance_event_scheduler` 在播放时复用空闲上传端口作同步预览读取，保持原播放读指针、事件次序、容量和 UART 行为。没有复制完整曲谱，也没有在逐像素路径中遍历事件。

新增 `performance_piano_roll.v` 从已加载的事件中配对起止，每个可见键记录开始时间及同键重叠计数。两个 208 行 × 64 bit 小图分别存放音符主体和起音边，端口 A 扫描/读改写，端口 B 连续显示；完整图在 VSYNC 交换。图行 RAM 的读地址来自原始 raster Y，结果与现有 raster entry 寄存器对齐，页面和合成器的总七拍延迟保持不变。

同键同时叠加的多个声部显示为它们的并集，最后一个匹配的 Note Off 才结束。该图是演奏提示，不对正确按键或节奏给出评分，也不改变现有实体键跟弹判定规则。
