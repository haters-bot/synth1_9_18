# I2S 音频总览与频谱主频标记升级（2026-10-27）

> 本页记录 20:12 的早期局部检查点，已由 `I2S_SIX_WINDOW_UPGRADE_2026-10-27.md` 接续。下文的示例回退、全高竖线和平均绝对幅度显示已被替换，不能作为当前实现说明或整轮完成依据。

## 本轮目标

按比赛演示优先的方向，把 VISUALIZATION 第一窗从静态音符/力度示意改成真实 I2S 音频总览，并为实时频谱增加当前能量最高频带的视觉标记。I2S 接收、波形、相位、频谱、历史和电平的既有数据通路保持不变。

实际工作副本：`D:/github/synth1_9_18/2_ui_touch_hub`。

## 已实现

- 第一窗标题改为 `01 AUDIO OVERVIEW`，说明改为 `I2S PCM / OVERVIEW`。
- 第一窗使用同一条实测 PCM 链路的 `meter_peak`、`meter_avg`、`clip_hold`：
  - 峰值条：绿色；
  - 平均绝对幅度条：青色；
  - 削波保持条：红色；
  - I2S 已连接但 128 点波形历史尚未填满时显示琥珀色等待线；
  - 断开或未建立采样时保留原静态示意作为回退，避免空白页面。
- `audio_fft_analyzer` 新增 `peak_band[4:0]` 输出。在 32 个真实频带发布时比较能量，保存当前最高频带。
- 第四窗实时频谱用黄色竖线叠加当前最高能量频带；绿色柱仍表示频带实际能量。
- 第六窗原有 `PEAK / AVG ABS / CLIP` 语义保持准确，没有把平均绝对幅度误标成 RMS 或 LUFS。

## 验证

- `python tools/test_i2s_visual.py`：I2S 接收、96 kHz/3.072 MHz 环回、左右声道配对、短槽拒绝、相位像素、字体 65536 格点、字符表 8192 项、实时波形和电平全部通过。
- `python tools/test_audio_spectral.py`：
  - 70 个 FFT 帧；
  - 3078 个 FFT 频点与浮点 DFT 对照，最大误差 7.854 LSB；
  - 192 个显示频带逐项对照；
  - 8、64、3 号测试频点对应的主频带标记全部通过；
  - 64 列历史、静音和断线清理通过。
- `python tools/test_touch_trace.py`：主/诊断顶层完整 Verilog 编译、串口事件回归和宿主解码通过。
- `python tools/test_knob_integration.py`：旋钮专项仍通过，说明本轮可视化改动没有破坏 SPI/C14 链路。

## 当前边界

- 本轮只完成源码、仿真和顶层编译，没有运行 Gowin P&R，也没有烧录新 UI 位流。
- 现有稳定 UI 仍是已验收 SRAM 版本；本轮升级需要后续单独构建、五类时序审计和现场抓屏。
- 第一窗现在展示 PCM 音频总览，不再声称能从 I2S 直接得到 MIDI Note/Velocity。I2S 信号本身没有明确的音符事件。
- 主频带标记是 32 频带级别的能量峰值，不是精确的 Hz 音高估计。第四窗原有频率范围说明仍为相对对数频谱，未校准为 dBFS。
