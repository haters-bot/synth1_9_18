# OSC A/B XY 与触摸后实体焦点修复

## 已确认目标

用户确认保留 X=OSC A、Y=OSC B，接受两板更新。音频板由用户在另一台电脑烧录；本机通过工程机部署 UI SRAM。最终目标仍为修改、构建、五类时序审计、SRAM 上板并由用户验收，不能以源码或仿真通过代替完成。

## 数据定义

现有三根 VIS 线保持引脚不变，扩展为 96 kframe/s、每槽 32 位的 I2S 时序：左槽上 16 位是最终输出 L，下 16 位是 OSC A；右槽上 16 位是最终输出 R，下 16 位是 OSC B。VIS BCLK=6.144 MHz。扬声器 MAX I2S 保持原来的 16 位、3.072 MHz。

OSC A/B 取各自开关/音量增益之后、混音和全局滤波/FX之前的独立信号，经过两份相同的 8 倍抗混叠 FIR，成对保存、同一帧快照。其延迟相同，不伪造相位。A/B同频同相仍可能是直线；改变相位、音高或波形才会改变轨迹。

UI 自动兼容旧 16 位槽：原波形、频谱、历史、总览和电平继续读取最终输出。只有完整的新 32 位槽对才产生 OSC A/B 有效事件；旧音频固件下第三窗显示等待 OSC A/B，不把 L/R 冒充 A/B。第三窗标题、坐标含义与脚注改为 OSC A:B XY、X OSC A / Y OSC B、PRE FX / SAME TIME，移除原 L/R 相关性游标与 BAL 数值。

## 焦点修复

旧 `selected_valid` 是持久状态，不能当成每拍触摸事件。触摸路由器现在在实际更新选择时发出单拍 `focus_event_valid`，ID 与事件同拍有效。实体旋转或按压更新独立显示焦点；释放和旧触摸状态不抢回焦点。触摸的编辑所有权和拖动灵敏度保持原逻辑。
