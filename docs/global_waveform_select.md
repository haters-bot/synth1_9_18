# 全局波形选择

## 当前实现

每个物理振荡器引擎并行例化四个组合波形读取模块：

- `sine_lut`
- `triangle_lut`
- `square_lut`
- `sawtooth_lut`

同一引擎中的全部TDM槽位共享这四个读取模块。当前槽位的
`phase_state[31:24]`同时送到四个模块，全局`waveform_select`再选择其中一个
16位有符号采样。这个结构不增加波表读取延迟，也不改变每槽位一拍的调度节奏。

## MIDI映射

上位机通过Control Change 21发送全局波形。FPGA使用控制值`[6:5]`：

```text
00：正弦波
01：三角波
10：方波
11：锯齿波
```

复位选择方波，以保持旧版本默认音色。

## 当前限制

- 四个组合波形读取模块会在每个物理引擎中各例化一份，结构清楚但不是最终的
  存储资源方案。
- 播放过程中切换波形可能造成采样值突变并产生轻微咔哒声；后续可以加入短交叉
  淡化。
- 方波和锯齿波为非带限波形。目前依靠768 kHz内部过采样和共享FIR降低混叠，
  不能完全消除所有高次谐波折叠。
- 扩展到大量波表帧时，应改用统一同步BSRAM，并给TDM核心增加波表读取流水线。
