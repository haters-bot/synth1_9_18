# 双振荡器波形选择

## 当前实现

每个物理振荡器引擎包含四个组合波形读取模块和一个同步多帧波表读取器：

- `sine_lut`
- `triangle_lut`
- `square_lut`
- `sawtooth_lut`
- `acid_wavetable_reader`

同一引擎中的全部TDM槽位共享这些读取模块。四个基本波形仍为组合读取；Acid波表
使用同步双读口ROM，同时读取相邻帧并线性插值。TDM核心用一级槽位元数据流水线
吸收ROM读取延迟，所以吞吐率仍是每拍一个槽位，整批结果比旧结构晚一拍左右。

## MIDI映射

上位机通过MIDI通道16分别控制两个振荡器的波形：OSC A使用CC21，OSC B使用CC29。
两者采用相同的数值编码：

```text
0：正弦波
32：三角波
64：方波
96：锯齿波
127：Acid多帧波表
```

复位选择方波，以保持旧版本默认音色。

## 当前限制

- 四个组合波形读取模块会在每个物理引擎中各例化一份，结构清楚但不是最终的
  存储资源方案。
- 播放过程中切换波形可能造成采样值突变并产生轻微咔哒声；后续可以加入短交叉
  淡化。
- 方波和锯齿波为非带限波形。目前依靠768 kHz内部过采样和共享FIR降低混叠，
  不能完全消除所有高次谐波折叠。
- Acid ROM已按BSRAM推断模板编写，但实际资源映射需要从Gowin综合报告确认。
- 当前每个物理引擎各有一个16×256×16位逻辑ROM；若双读口导致存储复制，资源会翻倍。
