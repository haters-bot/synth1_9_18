# Reverb V2 实现说明

## 目标

在不改变控制协议和顶层接口的前提下，继续使用以下三个参数：

- `Size`：空间尺寸；
- `Decay`：尾音衰减时间；
- `Mix`：干湿比例。

本次修改主要改善旧混响尾音偏短、金属共振明显、参数高值区变化不明显，以及固定点最低位残留的问题。

## 信号结构

```text
输入
  │
  ├─────────────── 干声 ─────────────────────┐
  │                                           │
  └─> 4 条延迟线 ─> 阻尼 ─> Hadamard 反馈矩阵 │
          │                                   │
          └─> 两级全通扩散 ─> 直流阻断 ─> 湿声 │
                                              │
                         Mix 交叉混合 <────────┘
                              │
                             输出
```

四条延迟线分别使用独立 BSRAM，并行读取。阻尼计算、反馈乘法和写回按通道分时完成，因此没有为四条反馈路径复制四套乘法器。Hadamard 矩阵、反馈乘法和 RAM 写回之间加入流水线寄存器，以缩短 50 MHz 组合路径。

## 三个参数的实际作用

### Size

四条延迟线使用不同的奇数长度，避免形成明显的整数倍共振。Size 改变时，每条延迟线只在自身指针回绕处更新长度，并且每次最多改变 64 个采样点。

延迟线增长时，新增 RAM 地址会先写入有效历史，再参与反馈，避免读到未初始化数据。

### Decay

Decay 经过分段非线性映射：

| Decay | 近似反馈增益 |
|---:|---:|
| 0 | 0.00 |
| 32 | 0.55 |
| 64 | 0.78 |
| 96 | 0.90 |
| 127 | 0.96 |

高值区保留了更细的长尾调节范围。反馈增益每个音频样本最多变化 `256 / 32768`，减少参数突变产生的咔嗒声。

### Mix

Mix 仍为线性干湿交叉混合：`0` 为纯干声，`127` 为纯湿声。非零目标每个音频样本变化 1，完整行程约为 1.32 ms。

## 固定点处理

- 延迟存储由 16 位扩大为 18 位，给反馈和扩散计算保留余量；
- 反馈乘法对正负数都向零截断，避免负数算术右移形成 `-1` 极限环；
- 湿声末端加入带最小泄漏的直流阻断器；
- 输出前继续进行饱和处理，避免回绕失真。

## 时序和资源预期

- 单个输入样本处理延迟：仿真测得 24 个 50 MHz 时钟；
- 完整全局效果链最大延迟：仿真测得 44 个 50 MHz 时钟；
- RAM 结构仍为 4 条主延迟线和 2 条全通延迟线；
- Size 和 Decay 的常数计算使用移位及加减，避免新增参数映射乘法器。

BSRAM 映射数量、DSP 数量和最终最高频率仍应以高云综合与布局布线报告为准。

## 建议上板试听顺序

1. 先用正弦波，设置 `Size=64`、`Decay=80`、`Mix=40`，确认尾音平滑且没有直流噪声。
2. 换为锯齿波，将 `Decay` 从 32 缓慢推到 127，检查尾音长度是否连续增加。
3. 保持长音，缓慢扫动 `Size`，确认没有明显爆音或整段静音。
4. 设置 `Decay=127`、`Mix=127` 连续演奏，检查是否出现自激、削顶或持续不衰减的最低位噪声。
