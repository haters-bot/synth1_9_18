# 三角波波表测试

> 该文件记录早期固定三角波测试。当前版本已通过MIDI CC21选择全局波形。

在三角波测试版本中，振荡器从 `sine_lut` 切换为 `triangle_lut`。原正弦表文件仍保留在工程中，
便于后续对比或切回。

三角波使用 8 位相位地址和 16 位有符号幅值：

```text
地址 0x00：     0
地址 0x40：+32767
地址 0x80：     0
地址 0xC0：-32768
```

模块根据地址高两位选择象限，低六位生成步长为 512 的线性斜坡。Note On
仍从零相位启动，因此不会因为波形替换引入非零起始电平。

板测时重点比较：

- 单音 Release 尾部是否仍出现偏高的调性声音；
- 单音音量是否与正弦波版本接近；
- 相邻复音的拍频听感是否发生变化；
- 三角波高次谐波经过 FIR 和 PT8211 输出后是否出现异常失真。
