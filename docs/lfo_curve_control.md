# 精简版LFO曲线与高精度参数控制

## 1. 实现范围

当前版本只把可编辑LFO曲线连接到全局滤波器的`Cutoff`。振荡器Warp LFO仍保持原有正弦波和7位CC控制，便于单独比较两条参数链路。

| 项目 | 当前值 |
|---|---:|
| 最少控制点 | 2 |
| 最大控制点 | 16 |
| 预采样表长度 | 256 |
| 输出参数精度 | Q7.7，共14位负载 |
| 上位机刷新周期 | 5 ms，约200 Hz |
| FPGA插值长度 | 512个96 kHz样本，约5.33 ms |

## 2. 控制点自由度

每个点包含时间、电平以及从本点连接到下一点的曲率和线段类型。

```text
time     0.0～1.0
level   -1.0～+1.0
curve   -1.0～+1.0
segment Linear / Curve / Step / Smooth
```

首点时间固定为0，末点时间固定为1；中间点可以左右移动。所有点都可以上下移动。开启“首尾连续”后，移动任一端点的电平会同步另一端点。

当共有`N`个点时，连续自由度为：

```text
N个电平 + (N-2)个时间 + (N-1)个曲率 = 3N-3
```

16点时共有45个连续自由度，另外还有15个离散的线段类型选择。

## 3. 线段计算

- `Linear`：相邻点之间线性变化。
- `Curve`：曲率为正时延后变化，曲率为负时提前变化。
- `Step`：保持前一点的电平，在下一点处跳变。
- `Smooth`：使用`smoothstep`，两端斜率均为零。

编辑完成后，上位机把曲线预采样为256点表。运行时相位位于两个表项之间时，再执行一次线性插值，避免LFO本身形成256级台阶。

## 4. 高精度UART消息

消息采用可与MIDI共存的非商业厂商SysEx格式：

```text
F0 7D parameter_id value_msb value_lsb F7
```

当前参数编号：

| parameter_id | 参数 | 数据格式 |
|---:|---|---|
| 1 | 全局Filter Cutoff | Q7.7，范围0～127 |

例如`Cutoff=110.25`：

```text
Q7.7 = 110.25 * 128 = 14112
消息  = F0 7D 01 6E 20 F7
```

普通通道16的`CC43`仍然有效，并会通过同一个插值器更新Cutoff，因此旧上位机和静态滑块保持兼容。

## 5. FPGA插值时序

每次收到新目标后，`parameter_linear_interpolator`从当前Q7.8数值出发，在512个`sample_tick`内到达目标。512是2的幂，因此步长可以拆成：

```text
绝对差值 = 基础步长 * 512 + 余数
```

基础步长通过右移得到，余数通过Bresenham累加器分散到512个样本中。整个模块不需要乘法器或除法器。

如果插值尚未结束就收到新目标，模块会从当时的当前值重新计算轨迹，不会直接跳到新值。最后一个样本强制写入目标值，避免定点余数累积误差。

## 6. 上位机操作

- 双击曲线空白处：增加控制点。
- 左键单击控制点：选中。
- 左键拖动：修改时间和电平。
- 右键控制点：删除中间点。
- “到下一点”：设置当前点之后的线段类型。
- “曲率”：设置`Curve`线段的弯曲方向和程度。
- “首尾连续”：同步首尾电平，避免循环边界跳变。

第一版沿用5 ms桌面定时器。该更新率既能在31250 bit/s链路上传输单路Cutoff LFO，也允许FPGA在音频采样域内完成连续插值。将来使用高速控制UART或SPI时，可以缩短刷新周期，并相应调整插值长度。

## 7. 已知边界

- `Step`线段会主动产生参数跳变，不适合高反馈梳状滤波的深度调制。
- 梳状滤波的延迟长度连续变化会产生正常的移调效应；高精度参数和插值用于减少控制台阶，不能消除这种物理现象。
- 同时开启两路Warp LFO和Cutoff LFO时，31250 bit/s链路接近满载。正式双输入架构应让控制单片机使用高速UART或SPI。
