# 上位机代表性音色库

## 1. 使用方法

运行`tools/midi_uart_sender.py`并连接开发板串口。在“MIDI参数”区域的“音色预设”
下拉框中选择音色，参数会立即载入；串口已连接时会自动发送完整配置。下拉框下方会
显示当前音色的简短说明。“重新应用音色”用于恢复被手动滑块或LFO修改过的预设参数。

切换预设会清除三条通用LFO的启用状态和全部LFO路由，防止上一个音色的隐藏调制继续
作用。已经按下的音符不会被上位机强制停止，建议在松开琴键后切换音色。

## 3. 波表依赖

“合成钢琴（波表8）”和“弓弦独奏（波表9）”要求SD/DDR波表包中存在对应编号。
如果DDR尚未就绪，FPGA会使用当前工程定义的安全回退路径，听感不会等同于预设名称。
“Acid 303风格”选择0号多帧波表；在外部波表通路未启用时，它对应工程内置的Acid
波表回退，在外部通路启用时则使用DDR中的0号波表。

## 4. 资源与复音注意事项

这些预设不增加RTL模块，也不需要重新综合布线，只发送现有MIDI CC参数。Supersaw
每个音符使用7个逻辑振荡器，宽广Pad每个音符使用5个；演奏较大和弦时，它们会比
单成员音色更早达到当前TDM槽位上限。钢琴、Sub Bass、电钢和风琴更适合测试较高复音数。

当前数值是第一版听感基线。不同音箱、PCM5102A输出电平和波表文件会改变主观结果，
可在选中预设后继续用滑块微调；确认满意后再把调整后的数值固化回预设字典。
